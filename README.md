# Personal Portfolio Website

This is my personal website and portfolio, built to showcase my projects, skills, and experience as a Computer Science graduate and aspiring software developer.  
The site highlights my work in **web development, game development, and IT support**, and serves as a hub where employers and collaborators can learn more about me.

## 🌐 Live Website
[Visit My Portfolio](https://omarcus123.github.io/about-me-website/)  

## 📂 Features
- **About Me** – Short introduction and background
- **Projects** – Highlights of my key projects with screenshots and descriptions
- **Skills** – Technical skills (languages, frameworks, tools, databases, etc.)
- **Resume** – Downloadable PDF of my resume
- **Contact** – Links to email, GitHub, and LinkedIn

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3  
- **Deployment:** GitHub Pages  

## 📸 Projects Shown
- **Academic’s List (Django Web App)** – A review/recommendation system for academic users (NDA-protected, no public repo)  
- **Mortal Kombat 1 Beginner Hub** – A responsive fan-made web app for fighting game tutorials
